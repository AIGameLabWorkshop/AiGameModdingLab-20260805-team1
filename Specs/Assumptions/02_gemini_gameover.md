# Spec_02: Gemini号泣ゲームオーバー画面

## 元の仕様書

| 項目 | 内容 |
|-----|------|
| **TRIGGER** | ゲームオーバーしたとき |
| **ACTION** | 画面いっぱいにGeminiの顔が出てきて号泣する |
| **TEST** | ゲームオーバーしたときに画面いっぱいにGeminiの顔が出てきて号泣すればOK |

## 曖昧だった点

1. **Geminiの顔の形状**
   - 「Geminiの顔」の見た目が不明確
   - 画像ファイルなのか、テキスト描画なのか

2. **号泣の表現**
   - 「号泣する」の表現方法
   - 涙？音？顔の変形？アニメーション？

3. **画面いっぱいのサイズ感**
   - どの程度のサイズか？
   - 画面全体を埋めるのか、中央に配置するのか？

4. **表示時間と消え方**
   - ゲームオーバー画面にずっと表示されるのか
   - アニメーションしながら消えるのか

## 作られた仮定

### 1. 顔の表現
- **決定：** Canvas で描画した単純な円形の顔（目玉・口・涙付き）
- **理由：** 既存コード（render.js）が Canvas テクスチャで動的に要素を生成しており、同じパターンで実装できるため

### 2. 号泣の表現
- **決定：** 以下の3つの組み合わせ
  - 顔が小さく揺れるアニメーション（水平方向、繰り返し）
  - 目から涙が落ちるパーティクルエミッター
  - 既存の「gameOver」SE をそのまま再生
- **理由：** ワークショップ向けのシンプルでわかりやすい表現

### 3. サイズと配置
- **決定：** 画面中央に配置、顔のサイズは画面高さの約60%
- **理由：** 「画面いっぱい」の自然な解釈

### 4. ライフサイクル
- **決定：** ゲームオーバー画面（overlayEl）が表示されている間、ずっと表示
- **理由：** ゲーム再開/リスタート時に自動で消える

## 実装ノート

### 実装内容

#### 1. `js/render.js` - 関数追加

**新規関数：** `createGeminiGameOverFace(scene, config)`
- Canvas テクスチャ（320×320px）で Gemini の顔を描画
- 黄色い円（#FFD700）を顔として描画
- 青い円（#1E90FF）を目玉として配置、黒い瞳孔を追加
- 悲しい口を弧線で描画
- 水色の涙（8px 大）を目の下に配置

**顔の表示と動き：**
- Scene に Image として配置、画面中央に配置
- 表示サイズ：画面高さの 60%（約 312px）
- Depth：100（最前面）
- tweens で左右 ±8px の揺れアニメーション（120ms、反復）

**涙のパーティクル：**
- 2つのパーティクルエミッター（左目・右目から発生）
- 発生位置：顔の目付近
- 生成頻度：150ms ごと、1つの涙を発生
- 下降速度：40-80 px/s
- 横方向ブレ：±10 px/s
- 重力：100 px/s²
- ライフスパン：2000ms
- 色：青（#64C8FF）、アルファ：開始 0.8 → 終了 0
- スケール：開始 0.4 → 終了 0

**新規関数：** `destroyGeminiGameOverFace(scene)`
- Scene に保持されている顔オブジェクトを破棄
- パーティクルエミッターを破棄

#### 2. `js/phaser-game.js` - 処理追加

**修正箇所：** `handleLifeLost()` 関数内

```javascript
if (this.lives <= 0) {
  this.phase = PHASE.OVER;
  this.ball.body.setVelocity(0, 0);
  sfx.play("gameOver");
  showOverlay(UI_TEXT.gameOver);
  // Gemini の号泣顔を表示する。
  RENDERER.createGeminiGameOverFace(this, CONFIG);
  return;
}
```

**修正箇所：** `resetWholeGame()` 関数冒頭

```javascript
resetWholeGame() {
  // ゲームオーバー画面の Gemini 顔をクリーンアップする。
  RENDERER.destroyGeminiGameOverFace(this);
  // 以降の処理...
}
```

### 仕様要件との対応

| 要件 | 実装 | 検証方法 |
|-----|-----|--------|
| **TRIGGER：ゲームオーバー時** | handleLifeLost で lives <= 0 の時に発動 | ボールを落とすとゲームオーバーになる |
| **ACTION：画面いっぱいに顔が出て号泣** | Canvas で描画した顔 + 揺れアニメーション + 涙パーティクル | ゲームオーバー画面で Gemini の顔が揺れ、涙が落ちる |
| **TEST：ゲームオーバー時に顔が出て号泣** | 上記が揃っていれば満たす | 顔・揺れ・涙が全て見える |

### エッジケースと制限事項

1. **複数回のゲームオーバー**
   - destroyGeminiGameOverFace が null チェック付きで安全に破棄
   - リスタート時に自動的に前の顔を削除
   - ✅ 問題なし

2. **画面リサイズ**
   - 固定解像度（360×520）なので不問

3. **パフォーマンス**
   - Canvas テクスチャは 1 回だけ作成（キャッシュ）
   - パーティクルは 2 個のエミッターのみ（軽い）
   - ✅ パフォーマンス影響なし

4. **音声**
   - 既存の `sfx.play("gameOver")` をそのまま使用
   - ✅ 追加の SE は不要

### 実装検証方法

✅ **以下の手順で検証：**

1. ゲームをプレイしてパドルを使わず、ボールを落とす
2. ゲームオーバー画面（"ゲームオーバー\nもう一度遊ぼう"）が表示される
3. **Gemini の顔が画面中央に表示される**（黄色い円、青い目、水色の涙）
4. **顔が小さく左右に揺れる**（継続的に揺れ続ける）
5. **目から涙が落ちる**（パーティクルが下方向に落下）
6. **「Restart」ボタンをタップ**またはスペースキーで新規ゲーム開始
7. **顔とパーティクルが消える**（クリーンアップ完了）
