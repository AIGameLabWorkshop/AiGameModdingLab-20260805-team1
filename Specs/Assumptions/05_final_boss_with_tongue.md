## 作られた仮定

### ボスの出現条件
- **最後のレベルの定義：** config.js で定義されているステージリストの最終ステージ（現在 stage 3）
- **出現トリガー：** 最終ステージで全ブロックが破壊されたとき
- **他のステージ：** stage 1、stage 2 では通常のボスシステムを利用（ボスが出現する）
- **最終ステージのみ：** stage 3 で全ブロック破壊時に「最終ボス」が出現

### ボスのサイズと見た目
- **ボスの半径：** 50px（通常ボスの30pxから拡大）
- **ボスの色：** 黄色（0xffff00）のまま
- **舌の見た目：** ボスの顔の下部に赤色（0xff0000）の舌を描く
- **舌の形状：** 半楕円形（上半分が円で下半分が細い舌）
- **舌の位置：** ボスの中心から下に伸びる

### ボスのHP と耐久
- **ボスのHP：** 10（現在の5から変更）
- **耐久性：** ボールが10回当たったら消える
- **得点：** ボス撃破時は100点（変更なし）

### ボスの動き
- **移動パターン：** 通常ボスと同じく左右にゆっくり振動（frequency = 0.5）
- **移動範囲：** 画面中央付近で左右60ピクセル幅で振動

### ステージクリア条件
- **最終ボス撃破：** ゲーム全体のクリア（PHASE.WIN）
- **通常ボス撃破：** 次ステージへ移動

---

## 判断の理由

### ボス出現の段階化
- 既存仕様（04_enemy_boss.md）では全ステージでボスが出現
- 新仕様では「最後のレベルのとき」と限定 → 教育的には、段階的な難易度上昇を実現
- stage 1、2 は通常難度、stage 3 が「最終ボス」という構図

### ボスのサイズ拡大
- ボール半径 5px → 通常ボス 30px → 最終ボス 50px という段階的拡大
- 画面の 360×520 における視認性・インパクトを考慮
- 「大きい」という仕様を視覚的に強調

### 舌の描画
- 「てした」= 日本語で「舌」
- 赤色の舌がボスの下から出ている見た目で、ボスの個性を表現
- ボスとしての「敵感」を高める

### HP = 10
- 仕様書に明記「10回あたったら死ぬ」
- 前の04_enemy_boss.mdでは HP=5 だったが、新仕様で明確に変更

### 修正ファイル一覧

2. **phaser-game.js** - `onBallHitBoss()` メソッド（行827-859）
   - ボス撃破時に描画要素（目・口・舌）を破棄する処理を追加

3. **render.js** - `decorateBoss()` 関数（行697-754）
   - `isFinalBoss` フラグをチェック
   - 最終ボスの場合：赤色の舌を描画
   - 通常ボスの場合：既存のニコちゃん顔を描画

### 実装の要点

#### spawnBoss() の実装パターン
```
const isFinalBoss = this.isFinalStage();
const bossRadius = isFinalBoss ? 50 : 30;
this.bossHp = isFinalBoss ? 10 : 5;
boss.setData("isFinalBoss", isFinalBoss);
```

#### decorateBoss() の実装パターン
```
const isFinalBoss = boss.getData("isFinalBoss");
if (isFinalBoss) {
  // 舌を描画（赤色 0xff0000）
  const tongue = scene.add.graphics();
  tongue.fillRect(boss.x - 6, boss.y + radius / 2, 12, 20);
  tongue.fillCircle(boss.x, boss.y + radius / 2 + 20, 8);
  boss.setData("tongue", tongue);
}
```

### 制限事項とエッジケース

1. **舌の描画方法** 
   - Graphics オブジェクトをボスのデータに保存
   - ボス消滅時に同時に破棄してメモリリークを防止

2. **舌の位置**
   - ボス生成時の位置で固定描画
   - ボス移動時に舌は追従しない（ボス位置更新のみ）

3. **他のステージでの動作**
   - stage 1・2：通常ボス（HP=5）で既存どおり
   - stage 3 のみ：最終ボス（HP=10、舌表示）
