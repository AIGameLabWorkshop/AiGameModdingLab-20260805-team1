# Specs/Samples README

このフォルダには、仕様書テンプレート（Specs/TEMPLATE.md）に沿って書かれたサンプルが入っています。

## サンプル一覧

### 1️⃣ 📦 シンプルパワーアップ班
**ファイル:** `01_simple_powerup.md`

**ぶっ飛び度:** ⭐ 地味

ゴールドブロック（黄色）に当たるとパドルが1.5倍に大きくなるシンプルな仕様。「簡単なアイデア」を仕様書として落とすのに最適なサンプルです。

---

### 2️⃣ 💥 爆発パーティクル研究所
**ファイル:** `02_wild_particle_explosion.md`

**ぶっ飛び度:** ⭐⭐ 派手

ボールがブロックに連続で当たった時（コンボ）に、虹色のパーティクルが爆発的に飛び散り、スコアが10倍になる仕様。複数の視覚効果を組み合わせたアイデアを、仕様書にわかりやすく整理するサンプルです。

---

### 3️⃣ ⏮️ タイムリバーサル開発隊
**ファイル:** `03_wild_time_reversal.md`

**ぶっ飛び度:** ⭐⭐⭐ 超派手

Rキーでゲーム時間を1秒前に戻すという大胆な仕造。複雑なアイデアを、TRIGGERとACTIONとTESTに簡潔にまとめるサンプルです。

---

### 4️⃣ 🎮 ボスバトル降臨プロジェクト
**ファイル:** `04_boss_shooting_battle.md`

**ぶっ飛び度:** ⭐⭐⭐⭐ 究極

ステージクリア時にボスが出現し、ブロック崩しからシューティングゲームへと完全にゲーム性が変わる仕様。ゲームの大幅な改造アイデアを、シンプルな3行仕様書で表現するチャレンジサンプルです。

---

## 補足

各サンプルは**仕様書テンプレート（Specs/TEMPLATE.md）** に沿って以下の3要素でまとめられています：

- **TRIGGER（いつ？）** - どのイベントで機能が発動するか
- **ACTION（どうなる？）** - ゲーム画面でどのような変化が起きるか
- **TEST（どうなっていれば大成功？）** - 実装が成功したかの判定基準

ワークショップの参加者は、このサンプルから選択して仕様書をAIに提出するか、テンプレートを使ってオリジナルなアイデアを仕様書にまとめてAIに渡します。子供たちは「何をしたいのか」を正確に説明する力を磨くことができます。
